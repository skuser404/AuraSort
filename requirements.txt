# Optional extras. AuraSort runs without them (standard library only); the installers add them before the first start.
#   Windows:       py -m pip install --user -r requirements.txt
#   macOS / Linux: python3 -m pip install -r requirements.txt   (inside a virtual environment, as the installer does)
# Pinned versions with ready-made wheels for Windows, macOS (Intel and Apple Silicon) and Linux, so nothing is compiled.
# Pillow 13.0.0 fixes the known vulnerabilities in 12.x (pip-audit, 2026-11-12) but needs Python 3.11+; there is no fixed
# 12.x, so Python 3.10 installs no Pillow and AuraSort uses its built-in thumbnails there.
Pillow==13.0.0; python_version >= "3.11"   # faster, smaller image thumbnails
pypdf==6.21.4    # reads more PDFs for Document Insights (a basic built-in reader is used otherwise)
