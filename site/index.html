AuraSort: a free, local file organizer and storage analyzer for Windows, macOS and Linux

Scan your folders or whole drives, see where your space goes, find duplicate files, check for corrupted files and sort your Downloads folder into tidy sub-folders. AuraSort runs only on your computer: nothing is uploaded, there is no account, and nothing is ever permanently deleted.

Download AuraSort Try the demo in your browser

Free and open source (MIT). Needs Python 3.10 or newer. No administrator rights needed.

Storage analyzer

See which file types, folders and single files take your disk space, on every drive, with real numbers.

Find duplicate files

Identical files found by size, then sampled bytes, then every byte. Keep the newest, review the rest.

Corrupted file checker

A read-only check of pictures, videos, documents and archives that says what is wrong and what to do.

Sort your Downloads

Move or copy files into one folder per type, with a preview first. Every move can be undone.

Safe by design

Project and system folders are left alone, "delete" means the Recycle Bin, and name clashes ask you first.

PIN lock

AuraSort opens behind your PIN and asks again before every move, copy, delete, undo or replace.

Install

Open a normal terminal in your user folder (not "Run as administrator").

Windows (PowerShell)

irm https://github.com/skuser404/AuraSort/releases/latest/download/install.ps1 | iex

macOS and Linux

curl -fsSL https://github.com/skuser404/AuraSort/releases/latest/download/install.sh | sh

Step-by-step instructions, the manual method, Android (Termux, experimental) and troubleshooting are in the README.

Private by default

AuraSort is a small program that listens only on 127.0.0.1 on your own computer. It has no telemetry, no analytics and no ads, and it reads only file names, sizes and dates when it scans. The optional AI document feature is off by default and works with a local engine. Read the Privacy Policy.
